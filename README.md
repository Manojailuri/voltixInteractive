# VOLTIX — scroll showcase (Vite + three.js)

A scroll-driven product page for the Voltix Electric Citrus can. As you scroll, the can moves
and turns through four story sections. The last section switches to **explore mode**, where
you can orbit, zoom and pan the model freely.
